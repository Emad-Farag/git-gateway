How to register a new developer

On the server, add their public key to the authority file:

echo "ssh-ed25519 AAAA... dev.name@company.com" >> ~/.ssh/authorized_keys

The e-mail must be part of the key comment (or an environment="GIT_AUTHOR_EMAIL=..." option). Then press Rescan applications — the user appears here automatically.

How does the developer create a key?

Each developer generates their key pair on their own machine and sends only the public half (.pub) to be pasted above. The private key never leaves their computer.

💻 Windows (PowerShell) 
ssh-keygen -t ed25519 -C "name@company.com"
# press Enter twice (empty passphrase is enough for identifing),
# stored at:  C:\Users\<user>\.ssh\id_ed25519.pub

# copy the PUBLIC key to the clipboard:
type $env:USERPROFILE\.ssh\id_ed25519.pub | clip

# or show it in the terminal to copy by mouse:
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub
🐦 Linux 
ssh-keygen -t ed25519 -C "name@company.com"
# stored at:  ~/.ssh/id_ed25519.pub

# show it (copy the whole line):
cat ~/.ssh/id_ed25519.pub

# or copy it straight to the clipboard (if xclip is installed):
xclip -selection clipboard < ~/.ssh/id_ed25519.pub
🍌 macOS 
ssh-keygen -t ed25519 -C "name@company.com"
# stored at:  ~/.ssh/id_ed25519.pub

# copy the PUBLIC key to the clipboard instantly:
pbcopy < ~/.ssh/id_ed25519.pub

# or display it:
cat ~/.ssh/id_ed25519.pub

The -C "email" part is important — it is what Git Gateway reads to know whose key it is and stamp commits with their identity. After pasting the key here, the developer connects with ssh user@server and starts working on the applications.
