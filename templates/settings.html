SSH identity on login

Git Gateway installs a small script that, when a developer opens an SSH session, matches their agent key fingerprint against ~/.ssh/authorized_keys and exports the matching e-mail as GIT_AUTHOR_EMAIL / GIT_COMMITTER_EMAIL plus a derived display name. The pre-commit hook then refuses any commit that is not stamped with an authorized e-mail.

Password logins bypass the per-key SSH session launcher, so a shared account password would let anyone skip the isolation and the identity rules. Disabling them means only keys present in ~/.ssh/authorized_keys can log in. Changes are validated with sshd -t and rolled back automatically if sshd rejects them — SSH is never left broken.
